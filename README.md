# Crypto Price Bot 💰
![Python](https://img.shields.io/badge/python-3.9+-blue)
![Discord.py](https://img.shields.io/badge/discord.py-2.0+-green)

Discord bot fetching real-time crypto prices from Binance API.

## Features
- ✅ `!price [crypto]` - Get current price
- 📊 `!chart [crypto] [days]` - Generate price chart
- 🔔 `!alert [condition]` - Set price alerts

## Setup
```bash
git clone https://github.com/votreuser/crypto-bot.git
pip install -r requirements.txt
cp .env.example .env
